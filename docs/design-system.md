# Design System — PUNTER PREDICTION

## Brand Identity
- Football: #059669 Emerald
- Basketball: #EA580C Orange
- Neutral: Slate 900/white with Indigo accent
- Logo: PP shield with sport indicator dot

## Tokens
- Radius: sm 6px, md 8px, lg 12px, xl 16px, 2xl 24px
- Shadows: soft, medium, large, sport-specific
- Typography: Inter sans, JetBrains mono

## Visual Language
Football: emerald gradients, emerald-50 bg, emerald borders
Basketball: orange gradients, orange-50 bg, orange borders
Both equal weight, no sport as afterthought.

## Components
- SportBadge: football/basketball pill
- ConfidenceBadge: Low/Medium/High/Very High with %
- RiskBadge: Low/Med/High
- ConfidenceIndicator: bar + circle variants
- RiskIndicator: icon + reason
- OddsDisplay: mono with movement
- AIReasoning: reasoning + blocks + disclaimer

## Themes
Light, Dark, System - class based, HSL variables, WCAG AA.

## Responsible Betting
All AI components include disclaimer, never guarantee.
